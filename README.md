# 🕺 make.it.bounce.
make.it.bounce. makes your texts bounce because the web is just too chill.

## 💥 Features
- Makes all letters on the page bounce infinitely
- Adds randomness to bounce height and timing
- Pure CSS animation injected by JavaScript
- Absolutely no purpose — just vibes

## 🔧 How to Use
1. Download this repo
2. Open `chrome://extensions/`
3. Enable Developer Mode
4. Click "Load unpacked" and select this extension folder
5. Watch the web bounce to life

## 🎉 Ideal For:
- Ruining your productivity
- Spicing up boring articles
- Making serious websites look very unserious
